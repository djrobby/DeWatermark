# DeWatermark

**DeWatermark** is a lightweight Sublime Text package that cleans pasted text by removing invisible Unicode characters, suspicious watermark-like markers, homoglyph substitutions, and unwanted typography commonly introduced by AI tools, websites, rich-text editors, and copied content.

Use DeWatermark as a clean-paste replacement when bringing text into Sublime Text.

## Features

DeWatermark automatically detects and cleans:

- Zero-width spaces
- Zero-width joiners and non-joiners
- Word joiners
- Unicode BOM characters
- Bidirectional and directional formatting characters
- Unicode isolate characters
- Selected Cyrillic and Greek homoglyphs
- Known unwanted marker characters
- Smart/curly quotes
- En and em dashes
- Unicode ellipses
- Non-breaking and unusual Unicode spaces

Every cleanup is logged to the Sublime Text console so you can see exactly what DeWatermark found, removed, or replaced.

## Usage

Open the Sublime Text Command Palette:

```text
Ctrl+Shift+P
```

Select:

```text
DeWatermark: Paste Clean
```

DeWatermark reads the current clipboard contents, cleans the text, and inserts the cleaned version at the current cursor or selection.

### Keyboard Shortcut

You can optionally bind DeWatermark to replace your normal paste command.

For example:

```json
[
    {
        "keys": ["ctrl+shift+v"],
        "command": "dewatermark_paste"
    }
]
```

Add the binding through:

```text
Preferences -> Key Bindings
```

## What Gets Changed?

DeWatermark operates deterministically - it does not use an AI model to rewrite or modify your text.

For example:

```text
U+200B ZERO WIDTH SPACE
```

is removed entirely, while:

```text
U+201C LEFT DOUBLE QUOTATION MARK
```

is converted to:

```text
"
```

and:

```text
U+2014 EM DASH
```

is converted to:

```text
-
```

Homoglyph characters that visually resemble standard Latin characters may also be converted to their Latin equivalents.

## Console Logging

Every operation produces a report in the Sublime Text console.

Example:

```text
======================================================================
DeWatermark
======================================================================
CLEANED - 1250 -> 1246 chars

Summary:
  Removed:  4
  Replaced: 7

REMOVED:
  4x  U+200B ZERO WIDTH SPACE  '\u200b'

REPLACED:
  3x  U+2019 RIGHT SINGLE QUOTATION MARK  ''' -> "'"  [TYPOGRAPHY]
  4x  U+2014 EM DASH  '-' -> '-'  [TYPOGRAPHY]

======================================================================
```

If nothing suspicious is detected:

```text
DeWatermark: Clean - no watermarks detected.
```

## Installation

### Package Control

Once available through Package Control:

1. Open the Command Palette with `Ctrl+Shift+P`
2. Select `Package Control: Install Package`
3. Search for `DeWatermark`
4. Press Enter

### Manual Installation

Clone this repository into your Sublime Text `Packages` directory:

```bash
git clone https://github.com/YOUR_USERNAME/DeWatermark.git
```

Restart Sublime Text if necessary.

## Philosophy

DeWatermark is intentionally small and predictable.

It does not attempt to determine whether text was written by a human or generated by AI. It simply identifies known Unicode characters, formatting artifacts, homoglyphs, and markers and applies explicit cleanup rules.

No network requests are made and your clipboard contents never leave your computer.

## Requirements

- Sublime Text 3 or newer
- No external Python dependencies
